# Early Tester Feedback

Please keep feedback short and concrete.

## 1) Retention
- Would you keep this extension installed after testing?
  - Yes / No / Not sure
- Why?

## 2) Interference
- Did the extension ever trigger when you did not want it to?
- If yes, where and what were you doing?

## 3) Trigger preference
- Which felt more natural?
  - Right Alt
  - Middle mouse
  - Both
  - Neither

## 4) Useful contexts
- Where did it help?
  - ChatGPT
  - GitHub
  - Slack / Discord / Telegram
  - Notion
  - Other

## 5) Broken contexts
- Where did it fail?
- Page/app name:
- Browser:
- Trigger used:
- What happened:
- Expected behavior:

## 6) One-sentence verdict
- I would use this because...
- or
- I would not use this because...
