# Privacy Policy

## One Tap Code Block

One Tap Code Block is designed to run locally in the browser.

## What the extension does

The extension only inserts or wraps Markdown fenced code blocks in supported editable fields when the user explicitly triggers it with:
- Right Alt
- Middle mouse

## Data collection

One Tap Code Block does **not**:
- collect user data
- store user data
- transmit user data
- sell user data
- share user data

## Network and third parties

One Tap Code Block does **not** use:
- analytics
- tracking
- remote servers
- accounts
- advertising
- external API calls

## Sensitive and personal data

One Tap Code Block does **not** collect:
- page content
- browsing history
- personal communications
- authentication information
- location data
- financial information
- health information
- personally identifiable information

## Code and execution model

- All code is packaged with the extension.
- The extension does not load remote code.
- The extension does not execute remote code.

## Summary

One Tap Code Block is a local-only utility extension. It performs its editing action only when the user explicitly triggers it, and it does not collect or send user data.
